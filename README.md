# 🌌 GALAXY AI

Python se bana Hindi/English voice aur text AI assistant.

## Features
- Voice aur text commands
- Time, date, jokes, calculator
- Chat memory
- Local AI (Ollama) support

## Kaise chalayein
1. Python install karo
2. `python galaxy.py` run karo
3. Browser mein `http://localhost:8000` kholo
